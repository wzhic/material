## 2. 本工作包目标

在现有 Electron Forge + TypeScript 官方脚手架上建立可继续开发的 React 渲染层，先让用户能够完成“选择一个本地视频或图片、选择行业、查看配置摘要、播放源素材并进入分析工作区预览”的可运行链路。

本工作包不调用模型、不执行脚本解析、不生成分析标签、评分或报告，也不保存正式分析记录。所有未接入能力在界面中显示准确状态，不能用演示结论冒充真实分析。

## 3. 当前实现

### 3.1 应用与渲染层

- 复用 Electron Forge 主进程、Webpack 和安全 Fuse 配置。
- 渲染层改为 React 19，使用 TDesign React 组件与设计变量；没有重新生成或覆盖官方脚手架。
- 浏览器渲染进程保持 `nodeIntegration: false`、`contextIsolation: true` 和 `sandbox: true`。
- 窗口默认 1440×900，最小 1120×720；不再自动打开开发者工具。

### 3.2 新建分析

- 单次选择一个本地视频或图片，使用浏览器 `File` 对象和会话级 `blob:` URL 预览。
- 通过 MIME 类型并辅以已知扩展名判断视频或图片；不支持的文件明确报错。
- 行业使用下拉选择，仅提供服饰和游戏。
- 产品保持“不绑定产品”；产品库业务尚未接入。
- 模型列表准确显示“暂无已配置模型”，因此真实“开始分析”保持禁用。
- 素材和行业就绪后可进入“工作区预览”，该入口明确说明不会调用模型、生成报告或保存记录。

### 3.3 分析工作区骨架

- 视频使用原生播放器，图片使用等比例预览；两者都只读取当前会话对象 URL。
- 播放器 / 对话区域分隔线支持指针拖动和键盘左右键调整。
- 时间轴高度分隔线支持指针拖动和键盘上下键调整。
- 时间轴保留情绪、镜头、画面、字幕、口播 / 声音和标签轨道，但只显示等待状态，不伪造片段或曲线。
- 对话区明确显示模型尚未接入；用户填写的关注点只作为本次页面上下文展示。

### 3.4 分析记录入口

- 一级导航保留分析记录入口，并准确展示“尚无已确认记录”的空状态。
- 搜索、筛选和记录列表保持禁用，等待正式分析、确认和 SQLite 持久化工作包接入。

## 4. 数据与安全边界

- 不读取或保存绝对路径，不复制源素材，不上传素材，不写 SQLite。
- 对象 URL 在素材替换或页面卸载时释放。
- 不采集 API Key，不创建模型配置，不把任何值写入系统安全存储。
- 不生成报告或分析记录，因此不存在未确认结果被误保存的问题。

## 5. 自动验证

| 检查 | 命令 | 目标 |
| --- | --- | --- |
| 代码检查 | `npm --prefix apps/desktop run lint` | TypeScript / TSX 代码规范 |

| 单元测试 | `npm --prefix apps/desktop run test` | 文件类型、草稿准入和大小显示 |

## 6. 回退

本工作包没有数据迁移或用户数据写入。若需要回退，撤销 `APP-0005` 内容提交即可恢复到 Electron Forge 初始页面；`node_modules`、`.webpack` 和 `out` 为忽略的本地产物，可重新安装或构建，不作为用户数据处理。

## 7. 后续工作拆分

1. 模型配置与系统安全存储：用户自带 Key、配置增删和任务显式选模型。
2. 本地媒体解析：媒体元数据、指纹、镜头 / OCR / ASR / 声音和时间证据合同。
3. Model Adapter 与 Tool Broker：脚本路径、大模型路径、可替换 Tools / Skills 和融合结果。
4. 报告预览与确认：模板、标签、评分、诊断、建议、不采纳与重新分析。
5. SQLite 分析记录：确认后原子保存、搜索筛选、素材恢复、反馈、删除和重新分析关系。
6. PDF 导出、真实 macOS / Windows 安装包及端到端验收。

这些工作属于同一产品需求下的独立工程任务，不自动扩大当前工作包的写入和验收范围。
