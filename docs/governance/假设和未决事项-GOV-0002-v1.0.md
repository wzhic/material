# 假设和未决事项-GOV-0002-v1.0

## 使用规则

- `已确认` 来自用户明确决定；发生变化时更新相关需求或决策。
- `未决` 在到达最迟确认阶段前必须关闭；不能把未决当成低风险事实。
- 影响范围、个人/敏感数据、安全、实质成本、不兼容迁移或不可逆结果的事项由用户决定。
- 低风险可逆项可由 Codex 采用推荐默认值，但需在任务中说明依据和回退方式。

## 已确认事项

| 编号 | 事项 | 结论 |
| --- | --- | --- |
| C-001 | 使用者 | 广告素材制作者与广告优化师 |
| C-002 | 项目形态 | `M + multi`；一个 monorepo、macOS/Windows/backend 三个独立发布单元 |
| C-003 | 客户端 | macOS/Windows 共享业务代码且功能一致，但分别构建、验收、发布和回退 |
| C-004 | 环境 | 客户端本地运行，后端公网运行 |
| C-005 | 身份与数据 | 涉及登录和鉴权；个人数据保存在客户端本地 SQLite；后端不保存账号数据 |
| C-006 | 自动操作 | 不自动发布广告，不自动调整广告预算 |
| C-007 | 分发 | 暂不上商店，但保留签名、公证、安装包和未来商店能力 |
| C-008 | 维护与 Agent | 预计 1 人维护，只使用 Codex，用户是关键决定与最终动作审核人 |
| C-009 | 技术基线 | 共享桌面端采用 Electron Forge + TypeScript，后端采用 uv + FastAPI |
| C-010 | 普通工作 | 清晰需求就是范围决定；可逆编辑、联网、常规依赖、测试、提交、功能分支 push、PR 准备和同范围返工不逐项审批 |
| C-011 | 子任务 | 允许创建子 Agent/子任务；只记录父任务、名称、目的、状态、时间和结果，不记录提示词、推理或秘密 |
| C-012 | 关键决定 | 验证豁免、破坏性/不可逆操作、敏感数据或显著安全/成本/不兼容迁移、最终合并/部署/发布由用户决定 |
| C-013 | CI | GitHub Actions 直接展示三平台结果；普通流程不要求用户发链接、配置本地读取 Token 或回写 CI 状态 |

## 未决事项

| 编号 | 类别 | 人话说明 | 当前处理 | 最迟确认阶段 |
| --- | --- | --- | --- | --- |
| O-001 | 风险 | 素材丢失、账号被盗、错误输出等最坏损失尚未量化 | 不据此降低数据、安全和发布边界；不阻断纯治理与可逆本地工作 | 首个相关产品需求定稿前 |
| O-002 | 身份/安全 | 身份提供方、令牌获取/失效/恢复和多设备行为未决定 | 不实现真实鉴权，不把凭据写入 SQLite、Git 或日志 | 鉴权需求定稿前 |
| O-003 | 数据 | SQLite 字段、敏感等级、加密、备份、导出和删除策略未决定 | 不创建业务 schema；凭据使用系统安全存储 | 数据模型需求定稿前 |
| O-004 | 后端数据 | 后端除账号外是否保存素材、任务或设备信息未明确 | 不能推定“后端不保存任何数据” | 后端数据需求定稿前 |
| O-005 | 环境/成本 | 公网后端环境数量、容量、预算、恢复目标未决定 | 当前 CI 不部署服务 | 首次部署前 |
| O-006 | 分发 | 签名、公证、安装和自动更新方案未决定 | 目录和标识避免封死未来路径 | 首次可分发构建前 |
| O-007 | 隐私/运维 | 遥测、崩溃报告和使用分析未决定 | 默认不采集 | 首次相关需求定稿前 |
| O-008 | 兼容 | 客户端与后端旧版本支持窗口未决定 | 新后端优先保持向后兼容 | 首次跨单元发布前 |
| O-009 | 仓库控制 | GitHub 分支保护与必需检查的最终远端设置尚未在本需求中修改 | Actions 先展示结果；最终合并由用户决定 | 首次合并前 |

## 更新要求

关闭未决事项时记录日期、用户决定、关联需求或 ADR 以及对现有任务的影响。新增高影响事项时，只阻断受影响的功能或阶段，不把无关的可逆本地工作一并冻结。
