# 假设和未决事项-GOV-0002-v1.0

## 使用规则

- `已确认` 是用户明确给出的边界；变化时需要新审核。
- `未决` 表示不能据此开工；达到“最迟确认阶段”前必须关闭。
- `延期` 不是低风险或不适用，只表示用户暂不评估。
- 影响范围、数据、安全、成本或不可逆结果的内容必须由用户确认。
- 低风险、可逆项可以记录推荐默认值，但必须写明依据和撤销方式；推荐不等于已批准。
