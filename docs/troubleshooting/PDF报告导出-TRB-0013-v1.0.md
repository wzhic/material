# PDF 报告导出问题排查 TRB-0013 v1.0

## 1. 导出按钮不可用或记录不存在

- 只有分析记录详情提供导出；待确认预览必须先确认并原子保存。
- 若记录已被删除或数据库不可用，导出不会创建文件。先确认该记录仍可从列表重新打开，再按分析记录存储排障文档检查数据库状态。
- 源素材移动、离线或权限失效不会阻断导出，因为 PDF 只读取已确认报告快照。

## 2. 系统保存窗口没有出现

- 检查是否存在被其他窗口遮挡的系统对话框。
- 退出全屏状态后重试；若 Electron 无法打开系统保存窗口，客户端显示错误且不创建目标文件。
- 不要通过向 Renderer 暴露任意文件写入能力绕过原生保存窗口。

## 3. 生成或保存失败

1. 换到有写权限且空间充足的位置重试。
2. 检查目标 PDF 是否正被其他程序独占，Windows 上先关闭占用程序。
3. 若错误发生在生成阶段，确认隐藏打印窗口可以加载本地 `data:` 文档并调用 `printToPDF`。
4. 若错误发生在落盘阶段，检查同目录是否允许创建随机 `.partial` 文件和 rename；失败清理临时文件，不得把半文件报告为成功。
5. 重试时系统窗口默认回到本记录上一次选择的目标；记录正文和反馈不因失败改变。

## 4. PDF 缺少内容或分页异常

- PDF 应包含标题、摘要、评分、分析章节、标签、诊断与建议、时间证据、局限和规则版本。
- 用户对话、可信反馈、模型配置、源素材、绝对路径和内部日志按设计不导出，不能作为“缺失内容”补回。
- macOS 与 Windows 字体和分页可以不同；若文字被截断，使用固定 A4 CSS、可断页卡片和系统中文字体复现，不以截图替代文字报告。
- 若 buffer 不以 `%PDF-` 开头，导出器应拒绝写入并提示重试。

## 5. 安全检查

- 用包含 `<script>`、链接、命令样式文本和路径文本的报告测试时，内容只能以转义后的普通文字出现。
- PDF 页面 CSP 禁止外部资源，打印窗口无 preload、无 Node、关闭 JavaScript并启用 sandbox。
- Renderer 只收到文件名和大小，不能收到用户保存位置的绝对路径。
- 不通过关闭 sandbox、开放导航或把报告 HTML交给远端服务解决导出问题。
