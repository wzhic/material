# 问题排查文档

本目录按问题域记录现象、影响、复现、证据、诊断、临时处置、根因、修复验证和防复发措施。治理门禁问题见 [治理门禁问题排查-TRB-0001-v1.0.md](治理门禁问题排查-TRB-0001-v1.0.md)。

产品库本地数据库、只读状态、写入冲突与 schema 不兼容见 [产品库本地存储-TRB-0002-v1.0](产品库本地存储-TRB-0002-v1.0.md)。

分析记录本地数据库、查询、反馈、非级联删除与 schema 不兼容见 [分析记录本地存储-TRB-0003-v1.0](分析记录本地存储-TRB-0003-v1.0.md)。

新建分析的系统文件选择、强指纹、当前会话预览、文件移动与同文件重新定位见 [本地素材引用-TRB-0004-v1.0](本地素材引用-TRB-0004-v1.0.md)。

不得用删除状态、关闭 Hook、跳过测试、直接修改受保护记录或改写 Git 历史作为排障手段。普通网络重试和范围内可逆修复不需要逐项确认。
