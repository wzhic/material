# 产品库本地存储-TRB-0002-v1.0

## 1. 适用范围

本文用于排查 APP-0006 产品库本地核心的数据库打不开、只读、写入冲突、列表读取失败和 schema 不兼容。不得通过删除数据库、清空用户数据或关闭治理门禁来“修复”。

## 2. 数据位置与隐私边界

数据库名为 `material-products.sqlite3`，位于 Electron 的系统 `userData` 目录。UI 和普通日志不得显示绝对路径、SQL、产品正文或堆栈；需要人工定位时，从操作系统应用数据目录进入。

产品库不包含素材、API Key 或报告。删除产品不等于删除迁移备份或未来报告快照；任何永久清理都必须另行确认影响。

## 3. 常见现象

| 现象 | 可能原因 | 安全处置 |
| --- | --- | --- |
| 产品库显示“无法打开” | 目录权限、文件损坏、schema 高于当前客户端 | 停止写入，保留原文件，核对客户端版本和目录权限后重试 |
| 可以查看但不能保存 | 数据库或目录只读、磁盘空间不足 | 保留表单，恢复写权限或空间后重新保存 |
| 提示其他窗口已更新 | `writeVersion` 与最新记录不一致 | 刷新产品，基于最新内容重新编辑；不得覆盖新版本 |
| 搜索无结果 | 当前筛选、关键词或数据规范化不匹配 | 清空条件；区分库为空与筛选无结果 |
| 保存失败但列表没有半条产品 | 事务已回滚 | 保留表单，排除空间、占用或输入问题后重试 |
| 提示客户端版本过低 | `PRAGMA user_version` 高于当前支持版本 | 升级客户端；不得把新库静默重建为旧 schema |

## 4. 诊断顺序

1. 记录页面显示的有限错误类型和发生动作，不复制产品正文。
2. 确认是否只有写入失败；若列表仍可读，按只读故障处理。
3. 检查系统应用数据目录的可读写权限和磁盘剩余空间。
4. 确认当前客户端版本与数据库 `user_version` 是否匹配。
5. 保留原数据库副本后再做完整性检查；没有已验证副本时不得覆盖原库。
6. 恢复条件后重启客户端，再从列表读回目标产品并执行一次新建、编辑和删除测试。

## 5. 恢复与验证

- 权限恢复：重启后列表可读，保存成功的产品可立即读回，旧产品不丢失。
- 冲突恢复：刷新后看到另一窗口的新内容，重新编辑产生更高写入版本。
- 空间恢复：失败期间没有半产品或孤立游戏上下文；恢复后一次事务完整成功。
- schema 不兼容：使用兼容的新客户端打开，不执行降级或静默重建。
- 数据损坏：当前工作包尚未提供自动恢复入口；保留原文件并暂停写入，进入后续备份恢复工作包处理。

## 6. 防复发与后续缺口

APP-0006 已提供事务、外键、写入版本、有限错误和只读降级，但尚未实现自动备份、恢复 UI、迁移中断恢复、10,000 条性能证据和 Windows 真机故障注入。这些缺口不能用 macOS 打包成功替代。
