# 工具执行底座-TRB-0005-v1.0

## 1. 适用范围

本文用于排查 APP-0010 的能力注册、Broker 策略、输入输出合同、脚本进程、取消 / 超时、有界并行、临时产物和结构化证据校验。当前没有接入真实 FFmpeg、OCR、ASR、音频或模型能力，因此“没有生成媒体分析结果”不是本底座故障。

不得通过放开任意命令、启用 shell、继承全部环境变量、暴露绝对路径、关闭 schema、提高资源上限掩盖异常、保留含隐私的 stderr / 输入输出或让 Skill 获得通用 Broker 句柄来修复。

## 2. 安全错误码

| 错误码 | 含义 | 诊断与恢复 |
| --- | --- | --- |
| `CAPABILITY_NOT_FOUND` | 请求的能力或明确版本未注册 | 核对 capability ID、安装 / 装配状态和版本；不能静默换成另一个工具 |
| `POLICY_DENIED` | 能力不在白名单，或 manifest 权限超出当前策略 | 比较注册 manifest 与运行策略；只补确有必要的最小权限 |
| `RESOURCE_BUSY` | Broker 直接调用并发达到当前安全上限 | 等正在运行的调用结束后由上层明确重试；不要绕过并发上限 |
| `INVALID_INPUT` | 输入不是 JSON 或不符合输入 schema | 修复调用方结构；不要放宽为任意对象 |
| `INVALID_OUTPUT` | Adapter 返回无效 JSON 或不符合输出 schema | 修复 Adapter 转换层；保存原始输出只能在隔离测试环境且需脱敏 |
| `OUTPUT_LIMIT` | stdout 或结构化输出超限 | 检查工具是否输出日志 / 二进制正文；改为临时产物并给出必要的合理上限 |
| `ARTIFACT_LIMIT` | 产物数量、单批总字节或路径合同不满足 | 删除非必要产物、拆分正式能力；不把配额调成无界 |
| `TIMEOUT` | 达到 manifest 与 Broker 上限中的较小值 | 确认工具是否卡住；允许用户明确重试，不自动切换或无限重试 |
| `CANCELLED` | 用户 / 上层取消 | 正常终止；等待 Adapter 清理，再由用户重新开始 |
| `EXECUTION_FAILED` | Adapter 或固定脚本非零退出 | 用固定脱敏样例复现；用户报告中只显示有限错误 |
| `INTERNAL_ERROR` | Broker 自身未分类错误 | 保留安全元数据和版本，建立范围内缺陷任务；不得写入原始素材或密钥 |

## 3. 常见现象

| 现象 | 可能原因 | 安全处置 |
| --- | --- | --- |
| 能力已安装但仍找不到 | ID / 版本不一致，或尚未在当前客户端装配 | 查看只读能力快照列表；按明确版本修正注册或调用 |
| 同一能力注册时报重复 | 相同 `capabilityId@version` 已存在 | 提升真实实现版本；不得覆盖旧版本或复用版本号 |
| Adapter 从未执行 | 输入 schema 或策略在运行前拒绝 | 核对安全错误码和 manifest；这是预期的 fail-closed 行为 |
| 脚本启动失败 | 可执行文件不是绝对路径、未安装、ACL / 签名 / 架构不兼容 | 验证固定安装路径和平台包；不要回退为 shell 搜索命令 |
| 脚本有结果却判输出无效 | stdout 混入日志、未返回信封、输出 schema 漂移 | 日志移到受控诊断通道；stdout 只保留一个 JSON 信封 |
| 取消后短暂仍见临时目录 | Adapter 正在响应取消并退出 | 等 Adapter 结束后自动清理；不在进程仍写入时强删目录 |
| 可选工具失败后整项失败 | 必要节点依赖该可选节点，或该节点实际声明为 required | 检查 DAG 与 failureMode；不要为了通过而把必要维度改成 optional |
| 图片证据被拒绝 | 区域为零、超出 0～1 边界或媒体类型错误 | 修正坐标转换并用边缘样例复验 |
| 视频证据被拒绝 | 结束早于开始、时间为负或超出素材时长 | 修正时间基准和媒体时长；不要截断后伪装为有效证据 |

## 4. 诊断顺序

1. 记录 invocation ID、能力 ID / 版本、安全错误码、状态和耗时；不记录输入原文、素材路径、脚本 stderr、Prompt、Key 或模型响应。
2. 从注册表只读快照确认能力 manifest hash、类型、权限、资源、失败等级和版本符合预期。
3. 用固定最小 JSON 样例分别执行输入 schema 和输出 schema 验证，区分调用方、Adapter 和工具原始输出问题。
4. 对 `POLICY_DENIED` 比较能力权限与 Broker 白名单；权限增加必须有明确工具需要，不因报错一次性开放网络 / 子进程 / 文件写入。
5. 对脚本问题以固定绝对可执行文件、固定参数、空或显式环境复现；确认 stdout 只有 JSON 信封，产物只写当前工作区。
6. 对超时 / 取消确认 Adapter 监听 `AbortSignal`，脚本进程能结束；若不响应，修复 Adapter，不扩大 timeout 代替终止能力。
7. 对编排问题画出最小 DAG，检查缺失依赖、环、必要 / 可选声明和并发上限。
8. 对证据问题用已知时长或图片尺寸的边界样例复验，再接真实媒体工具。

## 5. 临时产物恢复

- 成功但消费未完成：工作区暂时保留，消费层完成读取后调用 Broker `release` 或编排器 `cleanup`。
- 输入、策略或能力解析失败：尚未创建工作区，不存在待恢复产物。
- Adapter 失败、超时或取消：等 Adapter Promise 结束后清理，避免仍运行的代码写入已复用目录。
- 客户端崩溃：下次启动只清扫超过明确时限且名称严格为 `material-tool-run-<uuid>` 的目录；不清扫临时根中的其他内容。
- 路径逃逸或符号链接错误：整个调用失败，不采纳任何产物；检查 Adapter 为什么产生了不受控路径。

临时产物不是报告、分析记录或素材副本，不得人工移入正式数据库。若后续报告需要缩略图或证据文件，应由确认保存事务复制必要、已校验且无敏感内容的结果，并建立独立生命周期。

## 6. 验证边界

当前自动化能证明注册与合同、标准库脚本进程、超时 / 取消、资源与路径限制、DAG 调度和 EvidenceSchema 在共享 TypeScript 代码中工作。它不能证明真实 FFmpeg、OCR、ASR、音频或模型工具的安装、准确性、性能、许可证、网络可达性和平台兼容性。

排障后至少重跑类型检查、lint、全部 Vitest 和 Electron 打包，并确认审计 JSON 不含固定测试中的秘密值。接入真实工具时还需各自的真实样例、失败 / 超时 / 取消和 macOS / Windows 真机证据。不得通过删除失败测试、降低 schema、跳过打包或直接编辑任务状态宣称恢复。
