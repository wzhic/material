# 本地素材引用-TRB-0004-v1.0

## 1. 适用范围

本文用于排查 APP-0009 新建分析中的系统选择器、素材指纹、当前会话预览、文件移动/删除/权限失效、同文件重新定位和视频分段读取。不得通过扫描用户目录、把绝对路径复制到日志、关闭 Electron 隔离、跳过指纹或把不同文件强行绑定到旧分析来恢复。

## 2. 能力和数据边界

当前实现只维护进程内草稿会话。主进程内存临时保存真实路径和预期文件状态，renderer 只获得显示文件名、媒体类型、大小、SHA-256、状态、UUID 和 `material-local://` 预览地址。应用不复制源素材、不持久化草稿路径、不自动扫描移动目标。退出应用、移除素材或替换成功后，原会话不可恢复。

分析记录的历史素材句柄尚未接入。分析记录页显示“需重新定位”并不代表 APP-0009 已能为旧报告恢复播放；该能力必须等确认保存集成完成，不能手工往记录库写入路径。

## 3. 常见现象

| 现象 | 可能原因 | 安全处置 |
| --- | --- | --- |
| 系统选择器取消后没有变化 | 用户主动取消 | 正常；保留已有素材和表单配置 |
| 长时间显示正在生成指纹 | 文件很大、磁盘较慢或外接盘延迟 | 等待流式读取完成；不要重复选择或复制到应用目录 |
| 当前文件不是支持的视频或图片 | 扩展不在白名单、选择了目录或伪装文件 | 选择受支持的单个本地文件 |
| 校验期间素材发生变化 | 下载、同步或编辑程序仍在写文件 | 等文件稳定后重新选择 |
| 素材需重新定位 | 文件移动、删除、外接盘离线或权限失效 | 恢复磁盘/权限，或通过系统选择器选择同一文件 |
| 文件不匹配 | 候选的类型、大小或 SHA-256 不一致 | 返回选择原文件；若要分析候选，移除旧素材后作为新素材选择 |
| 预览突然停止 | 文件在播放期间变化、会话释放或读取失败 | 返回配置执行“检查素材”，按状态重新定位或重选 |
| 会话已结束 | 应用重启、素材被移除或旧会话已替换 | 重新选择；不要从日志或缓存恢复路径 |
| 视频能打开但不能拖动 | 文件编码/容器不受 Chromium 支持，或 Range 请求异常 | 先用支持样例复验；保留原文件，不转码覆盖 |

## 4. 诊断顺序

1. 从“新建分析”确认页面显示的是未选择、处理中、可用、需重新定位还是文件不匹配，记录有限错误文案，不记录绝对路径。
2. 若文件仍在原位置，点击“检查素材”；检查会重新计算完整 SHA-256，大文件需要等待。
3. 若文件移动或权限失效，点击“重新定位”，只选择预期的同一素材。取消是零变化。
4. 不匹配时核对页面显示的原文件名、候选文件名、媒体类型和大小；不要以相同文件名作为相同内容的证据。
5. 预览故障时先返回配置重新检查；若状态可用但特定编码仍无法播放，使用固定的受支持 MP4/PNG 样例区分协议问题和编码兼容问题。
6. 重启客户端后原草稿会话消失属于当前设计；历史报告恢复需等待后续持久句柄任务。

## 5. 失败恢复与不变量

- 新选择失败：旧选择、行业、产品和关注点不变；修复权限/磁盘后重试。
- 重新定位失败：旧引用不变；候选绝不静默替换。
- 原文件恢复：重新检查后可回到“本地可用”；无需创建正式记录。
- 协议 `404`：令牌过期或文件不可用；页面返回配置恢复，不根据 URL 猜路径。
- 协议 `416`：播放器请求了非法 Range；保留素材，复验客户端与固定样例。
- 应用退出：会话内真实路径被释放；源文件不受影响。

## 6. 验证边界

自动化验证 full-file SHA-256、安全摘要不含绝对路径、移动后同字节恢复、不同字节拒绝、原地变化检测、会话释放和 Range 解析。macOS 包构建验证模块能进入 Electron 产物，但不等于所有编码可播放，也不能替代 Windows 真机的选择器、长路径、ACL、占用和 Range 验收。

排障完成后至少读回：页面状态为“本地可用”、主动检查通过、图片可显示或支持样例视频可播放并拖动。不得用关闭 `contextIsolation`/sandbox、把 `file://` 路径暴露给 renderer、删除产品/记录数据库或修改测试掩盖失败作为修复。
