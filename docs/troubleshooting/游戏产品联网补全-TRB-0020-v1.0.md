# 游戏产品联网补全-TRB-0020-v1.0

## 1. 适用范围

本文排查产品库游戏名称联网授权、Bangumi 搜索、候选展示、取消、超时和字段应用问题。产品 SQLite、保存、重复提醒和备份恢复见 [产品库本地存储-TRB-0002-v1.0](产品库本地存储-TRB-0002-v1.0.md)。

## 2. 先确认影响边界

联网补全失败不应阻断手工填写、重复检查或保存。先确认用户输入仍保留、保存按钮仍可用，再区分授权、网络、上游响应或界面过期请求。不要为了恢复补全删除产品数据库、模型凭据、分析记录或其他用户数据。

## 3. 常见现象与处置

| 现象 | 可能原因 | 安全处置 |
| --- | --- | --- |
| 一直显示需要授权 | 尚未选择；授权文件缺失、损坏、超限；服务版本或发送字段变化 | 重新选择仅本次或持续允许；不要手改授权文件 |
| 选择仅本次后下一次又询问 | 一次授权已在一次出站请求前消费 | 这是预期；需要多次查询时选择持续允许 |
| 选择仅本次后未展示本次候选、立即又回到授权提示 | 授权按钮的强制查询与授权状态更新重复调度了同名自动查询 | 这是缺陷，不是预期的一次授权消费；核对 `query-scheduling` 回归测试，确保同名自动调度只抑制一次 |
| 显示离线 | DNS、代理、防火墙或目标网络不可达 | 恢复网络后由用户点击重试；继续手填不受影响 |
| 显示查询超时 | 10 秒内无结果 | 取消或重试；不要自动无限重试 |
| 显示查询过于频繁 | 上游返回 429 | 等待后由用户重试；不要自动换供应商 |
| 显示服务不可用 | 上游 5xx | 稍后重试或手填；保留表单 |
| 显示无法识别的数据 | 非 JSON、重定向、schema 变化、响应超限或非成功响应 | 保持失败关闭，核对上游 OpenAPI 后修订适配器与版本 |
| 搜索有结果但没有部分字段 | 上游没有白名单 infobox 或字段类型不符合合同 | 手工填写；不要读取未知字段兜底 |
| 应用建议后字段没变化 | 目标字段已有内容 | 这是防覆盖规则；用户可自行修改原字段 |
| 修改名称后出现旧结果 | 过期请求未被取消或 renderer 未核对 requestId | 检查取消与 stale-response 测试，不能应用旧候选 |

## 4. 授权检查

授权设置位于系统 `userData/game-product-enrichment/consent.json`，但排障日志和截图不得暴露绝对用户路径。文件只能包含 schema 版本、供应商 ID、适配器版本、`gameName` 发送字段和授权时间；若出现游戏名称、搜索正文、令牌或 API Key，应停止验证并作为安全缺陷处理。

持续授权只对完全匹配的供应商合同有效。更换服务、适配器版本或发送字段后再次询问是预期行为。文件损坏时客户端按未授权处理，不应崩溃或默认放行。

## 5. 网络与上游检查

真实网络检查必须使用固定公开游戏名称，不使用未发布产品名、客户数据或本地路径。核对请求：

- 域名严格为 `api.bgm.tv`，HTTPS，`POST /v0/search/subjects`；
- 查询只含固定游戏过滤和一个 `keyword`；
- 没有 Authorization、Cookie、API Key、素材、备注、版本、渠道或设备信息；
- 禁止重定向；响应限定 JSON 与 512 KiB；
- `User-Agent` 含项目与版本标识。

不要在终端历史、任务记录、CI 输出或截图中打印完整真实查询和响应。需要保留证据时只记录时间、HTTP 分类、候选数量和适配器版本。

## 6. 恢复与返工

同范围失败按以下顺序返工并重试验证：

1. 保留当前未保存表单，取消活动请求。
2. 用固定测试语料运行 `npm --prefix apps/desktop run test:product-enrichment`。
3. 若上游 schema 变化，只在适配器白名单内更新解析，同时提升供应商合同版本，使旧持续授权失效。
4. 重跑 Lint、TypeScript、全量测试和打包。
5. 若目标网络持续不可达，关闭补全入口或显示手填降级；替换服务必须新建任务并重新授权，不能静默切换。

授权存储写入失败时回到未授权，不得假装持续授权成功。取消失败或窗口销毁后仍有响应时，必须先修复 sender/requestId 隔离再继续发布验证。

## 7. 禁止操作

- 不直接编辑 `project-control` 受保护记录或删除失败验证。
- 不关闭 sender 校验、授权校验、响应大小限制或文本清理来“恢复可用”。
- 不在客户端嵌入项目共享搜索密钥。
- 不自动无限重试、静默更换供应商或复用旧供应商授权。
- 不把候选自动保存、覆盖非空字段、创建产品或打开上游链接与图片。
- 不通过删除产品数据库、分析记录或模型配置处理单纯的联网故障。
