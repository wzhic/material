# 规则包加载与评分-TRB-0008-v1.0

## 1. 适用范围与原则

本文排查 APP-0013 的四类固定规则包、行业 / 媒体注册表、规则版本启用、评分覆盖率和固定 / 动态标签。模型连接问题参照 [模型连接与凭据-TRB-0007-v1.0](模型连接与凭据-TRB-0007-v1.0.md)，工具证据问题参照 [工具执行底座-TRB-0005-v1.0](工具执行底座-TRB-0005-v1.0.md)。

排障不得通过删除 schema 校验、把图片映射到视频规则、跨行业回退、自动启用最高版本、把证据不足计为 0、修改旧报告快照或在规则包中加入 Prompt / Key / 素材正文来恢复。规则内容错误与证据不足是两类状态：前者阻止运行，后者保留维度状态并按覆盖门槛决定是否产生总分。

## 2. 常见现象、原因与恢复

| 现象 | 可能原因 | 安全恢复 |
| --- | --- | --- |
| 提示没有启用的行业 / 媒体规则 | 对应包未注册，或注册后未显式启用 | 核对精确 `industry + mediaKind`，注册通过后明确启用已验证版本；不要借用其他模板 |
| 规则包包含不支持字段 | JSON 拼写错误、把 Prompt / 页面字段或供应商配置塞进产品规则 | 删除越界字段并发布新候选版本，重新执行严格 schema 测试 |
| 图片规则被拒绝 | 声明了 `timeline` 或 `voice_and_sound` | 删除视频专有章节；图片不得伪造时间轴和声音分析 |
| 视频规则被拒绝 | 缺少时间轴或字幕口播与声音章节 | 在模板中补齐视频固定章节和版本，不以图片规则代替 |
| 权重不合法 | 维度重复、权重越界或总和不为 1 | 按同一评分版本重新校准所有维度，使总和精确为 1 并补固定样例 |
| 新 JSON 已注册但分析仍用旧版本 | 注册默认不激活，避免静默换版 | 完成隔离、样例和旧快照测试后显式启用新版本 |
| 改了返回对象却未改变后续解析 | 注册表返回防御性副本 | 修改源 JSON、提升版本、重新注册并显式启用，不依赖运行时对象突变 |
| 总分为空但有部分维度分 | 已评分权重覆盖率低于门槛 | 显示证据不足和各维度状态；补充真实证据后创建新分析，不伪造分数 |
| 不适用维度看似没有贡献 | `not_applicable` 按规则从适用分母移除 | 核对该状态是否业务上确实不适用；若只是没识别到，应标为证据不足 |
| 固定标签不存在或重复 | 模型输出了显示名而非稳定 ID，或同一标签提交多次 | 从当次规则快照选择固定标签 ID，去重后重新校验 |
| 动态标签被拒绝 | 与固定 ID / 显示名冲突、规范化后重复、facet 非法、超过 24 个 | 合并同义项，保留素材特有语义并引用当次证据；不要改名冒充固定标签 |
| 标签证据未知 | 引用了其他运行、已丢弃或格式非法的证据 ID | 只使用当前运行通过证据校验的 ID；证据缺失则不生成该标签 |
| 旧报告分数随规则更新变化 | 下游只保存版本引用或重新执行了评分 | 停止写入，恢复报告确认时的完整规则快照；旧报告不得重算 |

## 3. 建议诊断顺序

1. 记录行业、媒体类型、规则包 ID / 版本、模板 / 标签 / 评分版本和错误码；不记录素材正文、Prompt、模型响应或凭据。
2. 单独调用规则包解析，先处理未知字段、ID、版本、章节、目标、标签和权重错误。
3. 查看注册表清单和当前显式启用项，确认不是“已注册未启用”或选错行业 / 媒体。
4. 评分异常时逐维度核对状态、证据 ID、原始权重、适用权重、已评分权重与覆盖率；不要先改总分。
5. 标签异常时先执行 NFKC 与空白规范化，再核对固定标签 ID、动态标签 facet / 来源和证据集合。
6. 修复后运行规则专用测试、桌面端 lint、typecheck、全部普通测试、package、文档和治理回归。

## 4. 验证与防复发

每个规则内容版本必须有四类选择矩阵、目标隔离、权重总和、固定标签唯一性、图片 / 视频章节、显式启用、旧快照不变、最低覆盖率、证据不足不计 0 和动态标签冲突测试。更新一类规则时，其余三个当前版本和固定样例输出必须保持不变，除非同一任务明确列入范围。

产品校准评分时保存版本说明和固定样例期望，不在页面或模型 Adapter 中覆盖 JSON 权重。后续报告存储集成应读回完整快照并用历史版本解释分数；未知快照 schema 停止写入，保留原数据并提示升级。真实发布前分别在 macOS、Windows 使用相同固定输入核对模板选择、标签合同和评分结果；共享单测与打包不能替代真机报告交互。
